# SDL3_Expansion_UI_Modules
Some Expansion modules for SDL3 UI Development.

This Project Features some (still very much still in development) Expansion Modules for SDL3 and also offers a Starting Template for Projects using these Modules.

This Code may still include Bugs and Faults.

Among the Modules Provided here:
 - Added shape Drawing functionalety.
 - Edit Lines and Boxes.
 - A Blur/Transparency Module.
 - Simple Labels
 - Additional Utilitys for making development faster and easier.
